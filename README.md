# UEFA Champions League Countdown

A responsive countdown website for the UEFA Champions League kickoff .

## Live Demo

[View Live Project](https://omar-qassem-dev.github.io/UEFA-Champions-League-countdown/)

## About

This project displays a live countdown to the UEFA Champions League kickoff date .

The countdown updates every second and shows the remaining :

- Days
- Hours
- Minutes
- Seconds

## Features

- Live countdown timer
- Responsive design for different screen sizes
- Modern background and glass-style countdown boxes
- Hover effects on countdown boxes
- Click ripple effect
- Countdown automatically stops when the target date is reached

## Technologies

- HTML
- CSS
- JavaScript
- Google Fonts (Jost & Poppins)

## Challenges

One of the main challenges was creating a countdown that updates the remaining time accurately every second .

JavaScript calculates the difference between the current time and the target kickoff date , then converts the remaining time into days , hours , minutes , and seconds .

Another part of the project was making the countdown responsive so that the layout and countdown boxes work properly on smaller screens .

## Project Structure

- `index.html` — Project structure and content
- `omar.css` — Styling , responsive design , and animations
- `omar.js` — Countdown logic and ripple effect
